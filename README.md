2. **תרגול 3 ציורים מול מילה אחת**:

   - הילד קורא את המילה בקול רם ובוחר מבין 3 איורי וקטור (SVG) צבעוניים וידידותיים את התמונה המתאימה.
   - ללא תלות בקבצי תמונה חיצוניים (Zero 404s) – נטען מידית ועובד חלק בכל מחשב או טאבלט.

3. **חיזוק חיובי בהצלחה**:
   - מנגינת הצלחה הרמונית ונעימה (Web Audio API).
   - אנימציית זיקוקי קונפטי רכים בצבעי פסטל.
   - מחמאות מגוונות ומעצימות בעברית ("כָּל הַכָּבוֹד!", "אַלּוּפִים!", "קְרִיאָה מֻשְׁלֶמֶת!").

4. **עידוד לתיקון בעת טעות (ללא תסכול)**:

   - המשחק מעודד להביט שוב בניקוד, לקרוא לאט ולבחור שוב מבין האפשרויות הנותרות עד להצלחה.

5. **אנימציית צבירת נקודות מרהיבה**:
   - בעת בחירת התמונה הנכונה, כוכבים זוהרים עפים ישירות מהקלף הנבחר אל מד הנקודות בראש העמוד.
   - תג `+10` צף, מד הנקודות רוטט בשמחה, ומד רצף ההצלחות (Streak) מתעדכן.

6. **עזרי קריאה פדגוגיים מיוחדים**:
   - **🔊 הַשְׁמָעָה**: הקראת המילה בקול אם הילד/ה מתקשים וזקוקים לעזרה (Web Speech API).
   - **🧩 פֵּרוּק לִתְנוּעוֹת**: לחיצה על הכפתור מפרקת את המילה להברות/תנועות עם נקודה תומכת מתחת לכל הברה (למשל: `כֶּ • לֶב`, `תַּ • פּוּ • חַ`).
   - **🎤 קָרָאתִי בְּקוֹל!**: כפתור חגיגי המעניק פידבק מעודד ברגע שהילד קרא בקול רם לפני הבחירה.

7. **עיצוב פסטלי ומרגיע**:
   - שילוב צבעי מרווה, מנטה, קרם וגווני פסטל חמימים ורגועים, למניעת עומס חושי ולשמירה על ריכוז הילד.
